# Zhenxing Guo academic website

A lightweight static academic website designed for GitHub Pages. No Jekyll theme or build step is required.

## Deploy to GitHub Pages

1. Back up the current repository.
2. Replace the repository contents with the files in this folder.
3. Commit and push to the branch used by GitHub Pages (usually `main` or `master`).
4. In **Settings > Pages**, choose **Deploy from a branch**, then select the branch and `/ (root)`.
5. Keep the `CNAME` file if you want to use `zhenxingguo.org`.
6. In **Settings > Pages**, confirm the custom domain is `zhenxingguo.org` and enable **Enforce HTTPS** once GitHub reports the DNS check as successful.

## Update content

- Homepage: `index.html`
- Research: `research.html`
- Publications: `publications.html`
- Teaching: `teaching.html`
- Software: `software.html`
- Styling: `styles.css`
- CV: replace `assets/ZhenxingGuo_CV.pdf` with a newer PDF using the same filename
- Portrait: replace `assets/profile.jpg` with a new photo using the same filename

## Important

The content was rebuilt from the materials in the archived website. Please review dates, publication status, course offerings, contact details, and the CV before publishing, since some source material is older.
